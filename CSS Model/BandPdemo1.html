Borders and Padding Demonstration

This page demonstrates various border styles, border radii, and padding values.

Solid Border

This box has a **solid** border and even padding on all sides.

Dashed Border

This box features a **dashed** border and standard **rounded corners**.

Double Border

A **double** border with different padding values: Top/Bottom are less than Left/Right.

Groove Border

This box uses a **groove** border and more aggressively rounded corners.
