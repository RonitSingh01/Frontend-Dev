Gradient Background Demonstration

Exploring Linear and Radial CSS Gradients.

Linear Gradient

This background uses a **linear gradient**, transitioning smoothly from one color to another in a straight line (bottom-right to top-left).

It also features `background-attachment: fixed` to create a **parallax-like scrolling effect** on the background image.

Radial Gradient

This background uses a **radial gradient**, transitioning outward from a central point (the center of the box) in a circular pattern.

The background colors used are different from the linear section to provide visual distinction.
