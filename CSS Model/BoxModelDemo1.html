CSS Box Model Exploration

Understanding Content, Padding, Border, and Margin.

1. Standard Box Model (content-box)

The browser's default behavior, where the **width/height** only include the **content** area. Padding and border are added *on top* of the declared dimensions.

Content Area (300px width)

2. Modern Box Model (border-box)

Using box-sizing: border-box; ensures the declared **width/height** includes the **content, padding, and border**. This makes layout math much simpler.

Content + Padding + Border (300px total width)
